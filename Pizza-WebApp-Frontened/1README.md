# 🍕 Pizza Web

A responsive **Pizza Ordering Website** developed as a front-end web development project.

### Technologies

* HTML5
* CSS3
* JavaScript

### Features

* Pizza menu
* Custom pizza builder
* Shopping cart
* Checkout page
* Order history
* User profile
* Login & Sign Up
* Responsive design

### Project Purpose

This project demonstrates my skills in **HTML, CSS, JavaScript, responsive design, and interactive web development**.

### How to Run

Open `Home.html` in a web browser or use **Live Server** in Visual Studio Code.
